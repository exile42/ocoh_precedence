# ocoh_precedence
Outlands Heralds Precedence DB v1.3 

This repository is the PHP v3 version of the Outlands College of Heralds Precedence database. It builds on an outdated version of EZ_SQL, and is designed to be deployed on a LAMP environment.  It needs to be updated to a more modern version of PHP.
